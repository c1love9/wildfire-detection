# 辅助复核工时与检测框IoU补充说明

辅助复核单幅有效用时由项目负责人实测提供，约5秒/幅。未保存该次实测的样本数量和逐图配对日志，因此以下总工时为推算，不写成700幅全量实测。纯人工基线来自同一200幅的A/B原始独立标注计时：A共1751.840秒，B共2012.665秒。两人的总时间除以400次独立提交，得到单人单幅均值9.4113秒，不将两人的工时相加后除以200来夸大节省。

|工时方案|单幅秒|700幅预计分钟|
|---|---:|---:|
|纯人工A基线|8.7592|102.19|
|纯人工B基线|10.0633|117.41|
|纯人工合并均值|9.4113|109.80|
|预标注后人工复核|约5|约58.33|

总工时按“图像数×单幅秒数÷60”估算；节省率为“1－辅助复核单幅时间÷纯人工单幅时间”。据此700幅预计节省51.46分钟，约46.87%。分别使用A/B基线时，预计节省43.86～59.07分钟、42.92%～50.31%；这是两名标注者的差异范围，不是置信区间。估算仅覆盖查看和修正标注的人工作业，不含模型推理、环境准备、导出和无关等待；假定抽样与全部图片的难度、质量标准相近。未进行同人同图的随机配对实验，不据此声称严格因果提升。原始计时和人工提交不改写，也不生成700条假计时。

## 检测框IoU的解释

同一200幅原始A/B参考保持不变。按类别一致、置信度从高到低、一对一IoU≥0.5匹配；平均IoU只计算匹配框，须同时报告未匹配数量。

|候选版本及参考|匹配框平均IoU|匹配数|未匹配预测框|未匹配人工框|
|---|---:|---:|---:|---:|
|原Tiny对A|0.7353|122|273|148|
|原Tiny对B|0.7518|110|285|179|
|增强预标注对A|0.7317|128|114|142|
|增强预标注对B|0.7416|123|119|166|

这些数值属于检测框定位一致性，不是SAM掩码IoU。增强候选的P/R改善而匹配IoU略降，应同时披露；没有人工分割参考时，mask IoU及面积占比误差保持未知。原题没有要求额外强制标700幅掩码。本轮不重训模型、不改标签、不伪造参考掩码。
