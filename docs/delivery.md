## 现场演示顺序

可直接照着操作的步骤、讲解提示、设备故障处理见[现场演示操作指南](live_demo_guide.md)。本机可打印Word位于`artifacts/live_demo_20261108/智能火灾报警系统现场演示操作指南.docx`，共7页，首页为一页速查。

选择通道和本人模型 → 图片/视频检测与SAM → 面积和等级趋势 → 连续确认报警 → 截图与实际前后片段 → 历史地图回放 → 50轮曲线 → 统一模型比较与优化结果。摄像头使用设备现场可用状态；录像不保存个人摄像头画面。演示画面不冒充独立精度测试。

新版录像由scripts/record_final_demo.mjs实际操作生产数据页面。它同时检查11个页面、运行锁定、暂停冻结帧、趋势CSV、历史视频播放和真实实验结果可见。报告和指南分别由模板构建器与指南构建器生成，使用文档运行环境；每次编辑后均需逐页渲染检查。
