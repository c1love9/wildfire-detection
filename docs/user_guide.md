# 智能火灾报警系统完整使用指南

版本日期：2026年10月22日。适用项目：c1love9/wildfire-detection。本机目录：D:\GPTWORK\fire-alarm-system。

本指南帮助你独立启动系统、演示检测与报警、查找已保存的结果，并在正式数据准备好后完成标注、训练和评测。已有电脑直接从第一章开始；换电脑时先执行第二章。后面的章节按侧边栏页面顺序说明操作。

当前交付状态为“系统功能、实验工具和材料框架完成”。本机已登记700幅候选图像、300段视频和同批200幅A/B双提交；最终数据复核、独立性协议说明、充分收敛训练、独立测试、实际面积误差、工时节省和优化效果仍需完成。页面里的演示结果和自动化测试结果不能填成正式实验成绩。

## 一 已配置电脑的快速使用

### 启动和关闭

1. 打开项目文件夹 D:\GPTWORK\fire-alarm-system，双击“启动项目.cmd”。保留启动窗口。
2. 浏览器打开 http://127.0.0.1:8501 。首次打开会加载模型，稍等页面完成。
3. 如果侧边栏折叠，点击左上角展开按钮。页面名称中的英文用于与界面对应。
4. 结束时先在 Demo Videos 点击“停止检测”，等待报警片段生成完成。若有训练任务，先决定等待或取消。
5. 在启动窗口按 Ctrl+C 关闭网页服务。关闭网页标签不会可靠地停止后台训练，摄像头也应主动停止后再离开。

### 五分钟走通演示

1. Home 保持 Fire Detection 和 fire_n，确认内置图片能显示检测框；可开启“火烟像素分割”查看面积。
2. Channels 查看“监控通道 A/B/USB”的绑定。进入 Demo Videos，将“视频来源”选为“命名通道”，选择“监控通道 A”。
3. 保持 GPU 可用时选择 GPU；展开“检测设置”，按需开启分割。展开报警与录制设置，确认“保存报警截图和片段”开启。
4. 点击“开始检测”。核对火焰和烟雾数量、彩色掩码、面积曲线、关注到报警的变化，出现弹窗后“确认并关闭”。提示音须主动勾选才播放。
5. 检测十几秒素材时间后停止。进入 Alarm History，刷新记录、选择事件，查看历史位置、截图、视频和面积趋势，下载 CSV。
6. 进入 Comparison，用现有演示图片运行并排检测。没有自训模型和独立测试数据时，统一测试评测显示待评测是正常状态。

建议初次用默认参数。视频按每帧处理，开启分割后的处理时间可能明显长于素材时长；画面中的“视频时间”与电脑上实际等候的时间不同。

## 二 新电脑安装和模型准备

### 环境要求

本项目验证环境为 Windows x64、Python 3.11、NVIDIA 显卡及匹配驱动；本机使用 RTX 5060 Laptop GPU 约8GB显存。CPU可进行检测，SAM和GroundingDINO在CPU上可能较慢。锁定依赖针对本项目Windows环境，不保证其他操作系统直接复用。

准备 Git、Python 3.11 和支持 libx264 的 FFmpeg。FFmpeg 和 ffprobe 应能在新打开的终端中运行。pip安装不包含这两个外部程序。保留足够磁盘空间：依赖和模型需数GB，数据导出与每次训练还会产生独立副本。

### 获取代码和安装依赖

在 PowerShell 中执行下面的命令。已存在项目时在原目录更新代码即可，不要重复克隆覆盖数据。

```powershell
Set-Location D:\GPTWORK
git clone https://github.com/c1love9/wildfire-detection.git fire-alarm-system
Set-Location D:\GPTWORK\fire-alarm-system
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip check
ffmpeg -version
ffprobe -version
```

依赖检查应显示 No broken requirements found。执行命令时使用项目的 .venv\Scripts\python.exe，避免调用系统里另一个Python。也可使用 scripts\setup.ps1 安装，但FFmpeg仍需单独准备。无需复制旧电脑的 .venv。

最低检测文件为 fire-models\fire_n.pt、general-models\yolov8n.pt。内置图片位于 demo-images，视频位于 demo-videos。上游模型和演示文件已在仓库历史中保留，正常完整克隆可取得；本机采用稀疏检出，仅恢复所需的小模型与素材。新训练、SAM和DINO模型不随Git推送。

### 准备可选模型

只做YOLO检测时可跳过这一步。分割前准备SAM，预标注或模型对比前准备GroundingDINO。首次准备需要联网；后续推理读取本地文件。

```powershell
.\.venv\Scripts\python.exe scripts\prepare_sam.py
.\.venv\Scripts\python.exe scripts\prepare_grounding_dino.py
```

两条脚本下载固定版本并校验文件。SAM为facebook/sam-vit-base，版本70c1a07f894ebb5b307fd9eaaee97b9dfc16068f，权重约375MB。DINO为IDEA-Research/grounding-dino-tiny，版本a2bb814dd30d776dcf7e30523b00659f4f141c71，权重约658MiB。文件及校验凭据在 artifacts\models 中，不要只拷一个权重文件。

### 启动及更换端口

```powershell
.\启动项目.cmd
```

若8501端口已被本系统占用，先检查是否已有可用页面。需要开另一服务时使用下面命令，并在浏览器访问对应端口。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start.ps1 -Port 8503
```

服务默认仅监听本机127.0.0.1。所有USB设备和“本机文件夹”指运行服务的电脑；手机或其他电脑浏览网页不能把它们的摄像头直接接成USB输入。

## 四 图片检测与像素分割

1. 进入Home，将 Select Model Type 设为 Fire Detection。Select Model Size 选 fire_n 或成功训练后的“自训 · 实验说明 · 任务尾号 · best”。General是80类COCO演示模型，不能替代火烟模型。
2. “推理图像尺寸”默认640。Inference Device选择GPU或CPU；显存不足时先使用较小模型和尺寸。
3. Confidence Threshold默认0.20，控制保留哪些候选框；IOU Threshold默认0.50，控制重叠框抑制，并不是对真值评估的IoU。
4. Select image source选择 Demo Image、Enter URL 或 Upload from Computer。网址应直接返回图片。上传接受PNG、JPG和JPEG；图片会先按手机方向信息摆正，再用于检测和掩码坐标，超过2400万像素时须先缩小。
5. 可勾选“开启火烟像素分割”。SAM读取本幅图片上的检测框作为提示，显示半透明掩码和轮廓。若无检测框，不会凭空发现框外目标。
6. 查看 Prediction 结果，点击 Download Prediction 下载带框PNG。分割开启并成功时还可分别下载火焰、烟雾、火烟并集的二值PNG掩码。

分割掩码的宽高对应摆正后的原图，前景像素255、背景0。同类取并集，火烟并集不会重复计入重叠部分。面积是画面有效像素占比，不换算平方米。分割失败为未知；成功但没有目标才为0%。火烟掩码并非人工参考真值。

图片页只处理当前图片，不建立连续观测报警。需要弹窗、事件日志、截图和前后片段时使用Demo Videos。

## 五 视频 摄像头与通道检测

### 选择输入和配置

1. 进入Demo Videos，在“视频来源”选择内置样例、上传视频、摄像头或命名通道。上传接受MP4、MOV、AVI、MKV。部分样例已有上游旧框，当前结果以本帧数量和检测明细为准。
2. 摄像头默认编号0；Windows优先尝试DirectShow，无法打开时停止后再切换Media Foundation。此页只在点击开始时打开设备。
3. 命名通道默认A和B分别绑定fire1.mov与fire2.mov，USB通道绑定0号设备。一次检测一个通道；修改绑定详见第七章。
4. 选检测模型、计算设备、置信度。展开“检测设置”调整推理尺寸、NMS和SAM分割；展开“报警规则”或“报警截图与片段”调整需要的参数。
5. “监控点位置与视角（模拟）”可选择是否记录位置、预设点和角度。命名通道按绑定点显示。这里的坐标和角度都是模拟值，不来自真实GPS或云台。
6. 点击“开始检测”。运行和暂停期间输入、模型、分割及报警参数锁定；先停止再修改并重新开始。

### 观察画面和控制状态

画面显示本帧火焰和烟雾数量、原图检测框、置信度、帧号或观测时间、处理速度，以及最后的报警等级。展开“当前帧检测明细”查坐标，查看“本次报警变化”与“面积与等级曲线”。实时曲线保留最多300个采样点，完整采样落盘，历史可导出。

|操作或情况|视频文件|摄像头|
|---|---|---|
|暂停|保留下一帧和素材时间，不新增采样|关闭设备并结束本观测段|
|继续|从下一帧接续原观测|重新打开设备，新段从零计时并重新确认|
|停止|结束当前观测，保存可用媒体|释放设备，结束当前观测|
|结束或断流|视频结束或异常，保留最后判定|观测中断，保留最后判定|

视频文件每帧处理，报警时间按素材时间。摄像头仅处理最新采集帧，跳过积压帧；报警依据本机单调时钟。相邻检测时间超过默认1秒时，实时观测会中断，不能跨未观察区间累计确认或判断恢复。遇到此提示，减小推理尺寸、关闭分割或用GPU后重新开始。

停止、断流、视频结束均不代表火情恢复。不要只看保留的最后画面判断系统仍在运行，应同时核对页面状态。离开摄像头页面后还有空闲超时关闭机制，但主动停止更容易确保设备及时释放。

## 六 分级报警 录制与历史回看

### 默认规则和调整方法

报警须满足相同类别、可匹配区域的连续证据。检测置信度决定进入系统的框；火焰和烟雾报警置信度决定哪些框用于报警。把检测阈值调得高于报警阈值，会先过滤掉低置信度证据。

|参数|默认值|含义|
|---|---|---|
|连续确认|3帧|同一类别 同一区域持续命中|
|火焰与烟雾报警置信度|均0.50|两类可分别确认|
|关注 预警 报警持续时间|0.5秒 2秒 5秒|均需满足连续帧确认|
|面积辅助预警|3%并持续1秒|有效分割下辅助升级|
|面积辅助报警|10%并持续2秒|有效分割下辅助升级|
|恢复等待|2秒|有连续观测且证据不再支持才降级或恢复|
|区域匹配IoU|0.10|控制前后帧框的关联|
|最大相邻帧间隔|1秒|防止跨长空档确认|
|报警媒体窗口|确认前5秒 确认后10秒|以首次确认时刻为中心|

以上为可调整的课程演示参数。小面积持续火情可按原时间规则报警；分割关闭或失败时，面积未知，原规则仍工作。总体面积展示使用同类与火烟并集；报警面积辅助针对连续关联区域，并非把所有分散区域直接相加升级。

弹窗在事件确认或新等级出现时提示，确认关闭不会清空事件。当前浏览器会话的普通刷新避免同一事件等级重复提示，彻底新开浏览器会话不共享确认记录。声音默认关闭，须主动勾选“允许报警提示音”；浏览器也可能要求用户交互才能自动播放。

### 截图和片段保存

开启“保存报警截图和片段”后，在首次确认时保存一张带框截图，每个事件一段静音视频。确认前0～30秒、确认后大于0且不超过60秒，总时长不超过60秒。录制缓存默认32MB、300帧，可能限制真正可用的前置时间。

片段在后续素材时间到达或观测结束后编码；页面可能显示收集中、编码中。FFmpeg缺失时仅保存截图并显示片段失败。提前停止、素材开头、缓存限制会导致前后时间不足，历史标为部分片段并注明实际范围。不是整段原视频导出，也不保证覆盖整场火灾。

### 查询和导出

1. 进入Alarm History，点击“刷新记录”。按输入来源、最高等级、通道筛选，最多显示500条匹配事件。
2. 点击“导出当前筛选 CSV”保存列表。表格日期为UTC，换算北京时间加8小时；视频时间或本段观测时间是相对秒数。
3. 在“查看事件变化”选择事件。检查模型、来源、权重校验值和推理参数快照。
4. 查看历史地图和角度、首次确认截图、视频回放、实际片段范围与截断原因。地图的点位是监控点，扇形仅示意方向，不是火焰位置或真实覆盖范围。
5. 查看事件期间面积与等级曲线，点击“导出面积趋势 CSV”。关闭分割或失败的面积为空；旧记录缺字段显示未记录，不补造数值。

报警日志在 artifacts\alarms\alarms.sqlite3，媒体在同目录media子目录。复制数据库时也要保留media；只备份CSV不能恢复截图、录像或全部历史。正在编码时先等待完成再关闭服务或备份。

## 七 命名通道和模拟位置

在Channels选择“编辑通道”，填写通道名称、输入类型video或camera、本地视频或USB编号，再选择关联模拟监控点，点击“保存通道配置”。两个输入控件都会显示，保存时按输入类型读取对应值。

配置写入configs\channels.json，下次新观测生效；先停止Demo Videos，再返回选择通道重新开始。切换后不会继承原通道的连续确认。历史保存当时名称、输入、位置、视角和模型，之后改名不会改写旧事件。

本地命名视频只能绑定demo-videos里的MP4/MOV/AVI/MKV，普通上传使用视频页“上传视频”。通道页编辑现有通道，不提供多路同时监控。监控点预设在configs\monitoring_points.json；页面手工调整位置和角度用于本次观测，重启后不要假定所有临时输入仍保留。

水平角0度向北、90度向东、顺时针；俯仰角负值向下。没有真实定位标定，不将画面占比转成平方米或米每秒。无法联网加载地图时，关闭“显示在线地图底图”仍可查看点位和方向。

## 八 数据导入 来源记录和划分

### 先建批次再导入

1. Dataset的“导入与采集”展开“新建采集批次”。填写名称、采集组编号、来源和说明；来源选自采、公开或演示/测试。
2. 同一次拍摄、同场景、同一原视频剪出的片段与抽帧使用同一采集组，防止训练和测试见到高度相似画面。公开素材抽帧仍标公开，不能因重新抽帧变成自采。
3. 填写场景内容fire、smoke、normal或unknown。normal和unknown各自单独选择，不能同时声明火烟；此声明不是目标框标签。室内外、光照、规模、距离、视角按实际填写。
4. 点击“创建批次”，确认“当前导入批次”正确。测试流程务必用演示/测试来源，避免污染正式统计。
5. 上传一个或多个文件并点击“导入上传文件”；也可展开本机文件夹导入，填绝对路径，决定是否递归，点击“导入文件夹”。每次最多5000个受支持文件。
6. 检查逐文件结果。图片按摆正后的像素去重并归档PNG，视频按文件哈希去重；重复素材可关联多个来源，数量不重复累计，来源冲突会单独显示。

支持图片JPG/JPEG/PNG/BMP/WebP与视频MP4/MOV/AVI/MKV。归档不移动原文件。若用USB采集，先停止实时检测并选择自采或演示批次，设置设备和1～30秒时长，点击截图或短片；这里保存未叠框原始画面，操作结束自动释放设备。

### 抽帧和数量统计

进入“素材与抽帧”，选择已入库视频和沿用批次，设置抽帧间隔与单次上限，点击“从所选视频抽帧”。默认每1秒一帧，最多500张；可设0.1～3600秒、1～2000张。系统按原时间顺序读取并继承原视频来源与组，时间异常会停止，已入库帧保留。

进入“统计与划分”刷新统计，查看去重图片/视频、抽帧数、正常图像、来源比例和场景分布，导出来源CSV及统计JSON。演示素材不计正式候选，来源和场景仍需人工核实。数量进度不是验收结论，最终以题目原文和老师对自采口径的确认为准。

### 冻结划分版本

设置train/val/test比例默认70/20/10、随机种子42，合计100%，生成预览。至少需要3个互不关联且含图片的正式采集组；系统把关联原视频、抽帧和重复素材整体分到同一集合，不拆组凑比例。比例可能偏离目标，应检查类别和负样本分布。

确认后“保存本次划分版本”，下载manifest和train/val/test清单。新增素材后旧版仍保留，当前指纹变化则要重新生成划分和导出。清单只记录素材分配，没有复核标签和训练目录，不能直接当成已完成训练数据集。

## 九 自动预标注 人工复核和YOLO导出

### 运行预标注

Annotations先填写“执行者/复核者姓名或编号”，选择“自动预标注”。确认本机DINO已准备。默认按fire与smoke分别使用英文同义词，以句点分隔；在“模型与推理参数”选择设备和阈值，候选框默认0.30、文本阈值0.25、NMS为0.50。

选择范围“尚无预标注的图片”“全部图片”或手选，单次最多100幅，默认20幅，再点击“开始自动预标注”。等待任务结束并检查失败项。新提示词生成新候选版本，不自动覆盖人工复核；空模型输出和失败记录都不能直接成为正常负样本。

### 人工复核画框

当前自动预标注默认提供“增强候选：Base + 火烟YOLO”，原Tiny方案可切换。700幅已追加增强版本；人工复核时选择最新“自动增强候选 Base+YOLO”并点击“采用所选预标注”加载。原版本与A/B原始提交保留，已有人工通过内容不会自动覆盖。默认参数、对比结果及26幅优先复核线索见[优化记录](preannotation_optimization.md)。

1. 切换“人工复核”，选择图片，确认原图尺寸和版本。需要使用另一候选时选择版本并点击“采用所选预标注”。此操作会替换当前未保存画布。
2. 在画布选择“画框”，按住拖出框；“选择/移动”可移动框、拖角缩放，点击框编号可选框。框类别选fire或smoke，可删选中框、清空或撤销。
3. 坐标编辑框使用原图像素，必须在图内且宽高至少1像素。先补漏检、删除误检，再核对类别。页面缩放不改变标签坐标。
4. 在“复核处理（可多选）”选择本图实际完成的处理：核对无误、补充漏标、删除误检/重复框、修改类别或调整框的位置/大小。说明自动生成，特殊情况才填“补充说明（选填）”；“核对无误”不能与修改操作同时选择。选项不替代画布上的实际修改。空框图片必须勾选已检查整图无fire或smoke，无需另写文字。点击“保存草稿”仅存工作版本，“确认复核通过”才允许作为已复核数据导出。
5. 检查人工修改记录，可下载单图完整记录JSON。如果另一窗口已更新版本，重新载入后再保存，避免覆盖他人修改。

画布未保存的内容可能随会话丢失，切页前先保存。普通复核记录中的停留时长不作为有效工时；正式工时使用Quality的可暂停计时和受控对照记录。

### 两种导出的用途

|导出类型|包含内容|用途|
|---|---|---|
|已复核标签ZIP|YOLO TXT 清单 修改记录|标签交付与审计，不含完整训练图片|
|YOLO训练数据集|images和labels的train/val/test data.yaml 审计快照|Training页面选择的完整输入|

在“YOLO导出”可选择通过的图片导出标签ZIP。要训练，必须先有当前划分、该划分全部图片的最新复核均通过，再点击“生成YOLO训练数据集”。生成目录在data\fire_dataset\exports；图片总量不超过128MB时另提供ZIP，大数据直接保存在本机目录。

YOLO导出固定0=fire、1=smoke，格式为类别、归一化中心x/y和宽/高。上游fire_n的类别顺序不同，检测运行时按类别名称适配，不能直接混用原始类别编号。已通过标签后又保存新草稿会阻止新导出；已有旧版训练快照保留其原标签。

## 十 YOLO训练 独立评估与切换模型

### 新建训练

1. Training填写执行者与实验说明，选择“新建训练”和“已复核YOLO数据集”。没有选项时先完成上一章的完整数据集导出。
2. 默认YOLOv8n使用上游COCO初始权重，新建fire/smoke检测头，不覆盖原报警模型。设置轮数、尺寸、batch、设备、优化器、学习率、种子、早停和多尺度开关。
3. 默认50轮、640、batch8、AdamW、学习率0.001、种子42、早停15；这是起始配置，50轮不保证收敛。显存不足先减小batch再考虑尺寸。正式方案依验证集决定，避免依据test反复调参。
4. 点击“开始训练”。任务在独立后台运行，同一数据目录一次一个训练或评估任务；切页面或网页服务重启不等于取消训练。
5. 在“任务与实验记录”刷新列表，选择任务，查看状态、轮次、损失/验证曲线、参数与工作日志。取消需点“取消当前任务”，等待到批次检查点，状态变成已取消后再开始新任务。

每次任务保存独立数据和初始权重副本、参数、环境、日志、曲线、结果与best/last。运行前后会校验快照，手工修改归档图像、标签或清单会阻止任务。不要为消除校验错误而手改凭据，应恢复原文件或重新导出并新建任务。

### 独立评估和指标理解

选择“模型评估”，指定成功完成的训练任务，选test或val及尺寸/batch/设备，点击“开始评估”。训练过程只用val选择best，不在每轮用test。独立test应在方案确定后运行。

结果显示Precision、Recall、F1、mAP@0.5、mAP@0.5:0.95及分项耗时。训练页P/R/F1取该评估集合上Ultralytics的最大平均F1点；与Comparison固定0.25阈值的P/R不可直接混合比较。某类没有参考目标时显示null或无参考目标，不能填0或100%。速度不包含网页、磁盘和摄像头完整链路。

任务成功后可“选择下载文件”，下载请求、参数、环境、数据凭据、指标、曲线和best/last。状态为completed只表示流程完成，精度是否达标需独立数据判断。系统重启导致的中断任务保留已有文件，目前应新建任务重试，不提供页面断点续训。

### 将best模型用于实际检测

成功训练后best自动出现在Home和Demo Videos模型列表，名称含“自训”和实验尾号。停止视频或摄像头后再切换；按需调整图像尺寸，重新开始。查看模型来源与权重校验值，日志会保存模型快照。权重缺失或被修改时显示不可用，不会静默换成另一个模型。

## 十一 模型对比和优化实验

### YOLO与GroundingDINO对比

Comparison选择YOLO模型、统一计算设备及fire/smoke提示词，填写执行者和说明。“图片并排检测”可上传图片或用演示素材，点击“运行并排检测”；只呈现结果，不从一张无真值图片算准确率。

“统一test评测”只允许选择本人成功训练的best。系统使用该任务冻结的独立test、同一640×640输入、batch1、FP32和同一设备；P/R/F1阈值0.25、匹配IoU0.50，AP用低阈值候选与0.50～0.95的IoU。提示词、参数、权重、逐图预测、耗时和资源保留在独立对比记录。

完成后在历史对比结果下载CSV及完整JSON。这里的DINO未微调，且也用于预标注，报告需披露；独立参考标签须来自真实人工流程。当前没有正式模型或数据时保持待评测。

### 固定尺寸和多尺度训练对照

Experiments选择设备、已复核数据、执行者与说明，设轮数及batch，保存成对配置。两组固定初始权重、数据划分、种子和其他参数，仅多尺度开关不同。依次启动baseline、等其完成，再启动multiscale；同一数据目录不能同时训练两组。

两组成功后点击“统一评估两组test”，统一640尺寸生成指标和“多尺度减基线”的差值，下载成对结果。差值可为负，不预设有效。失败组不覆盖重跑，排查后创建新实验对。

同页还可“运行样例前10秒策略对照”，在同一检测序列比较单帧触发与连续确认的次数和首次触发时间。没有事件真值时只是触发对照，不是误报率或漏报率结论。

## 十二 独立标注 面积误差与有效工时

### 双人独立标注、报告与分别导出

1. Quality选择“创建独立标注任务”，选图片，填写两名不同标注者和管理者，点击创建。分别保存A、B与admin访问码；原始访问码只在创建者当前会话显示，应及时妥善保存，数据库只存哈希。
2. A/B分别使用“独立标注”与自己的访问码，不能共享结果。初始画布不显示预标注和对方标注；按图片从零画框。
3. 点击“开始或继续工作计时”，工作间隙点暂停；超过60秒无活动会限制计时。切换本页的图片、访问码或工作区会自动暂停上一项，但离开整个页面或关闭窗口前仍应主动暂停。
4. 检查框或确认无火烟，点击“提交并锁定本图独立标注”，系统自动暂停计时并保存。无需先暂停或切图；按钮灰色时会显示原因。提交后本人只能查看已提交结果；未提交的画布与计时不可当成已落盘记录。
5. 两人全部完成前管理者看不到对比结果。完成后用admin进入“报告与导出”，可只读查看原图和A/B框，无须逐图仲裁。
6. 直接生成质量报告：预标注分别对A、B计算P/R/F1，同时保留A/B匹配框IoU、未匹配数量、工时和冻结版本。导出内容可选仅A、仅B或A/B完整包。系统注明是否达到200幅，自动化角色不算真人双标。

访问码用于应用内隔离，不等于系统账号或身份认证。只有实际两人独立操作与遵守流程，才能支持“双人独立标注”结论。A/B原始标注锁定保留；报告与导出不产生训练复核通过记录。最终训练标签继续通过Annotations人工复核与YOLO导出。

### 面积误差

选择“面积误差”，选对应归档图片和fire/smoke/combined类别，上传独立人工参考PNG与模型预测PNG。两个掩码须为与原图完全同宽高的二维二值图，仅接受0/1或0/255，不能上传彩色叠加检测图。填写执行者和参考来源，声明参考由人工独立绘制，再计算保存并下载记录。

结果含IoU、Dice、参考/预测画面占比、绝对面积误差百分点、相对误差。两个掩码均为空时IoU/Dice约定为1；参考为空时相对面积误差为null，绝对误差仍可计算。SAM自己生成的掩码不能作为评估同一模型的参考真值。

### 工时对照

选择“工时对照”，填对照组编号、人员、manual或assisted条件、实测有效秒数及方法。相同组与相同人员的两种条件才配对；同一个人同组同条件只保存一条，重复会提示唯一性约束。不同批次使用新的组编号。

保持任务难度、质量标准接近，并平衡执行顺序，才可解释工时差异。节省率可能为负；普通页面停留、无人操作时间或模拟秒数不证明真实节省。提交的独立标注时间和手工对照记录持久化，未提交的页面计时在服务重启后丢失。

## 十四 常见问题排查

### 页面打不开或启动窗口闪退

先在项目目录手工运行启动命令读取错误。确认.venv存在、使用Python3.11、安装依赖成功；端口已占用时访问已启动实例或改用8503。PowerShell阻止脚本时可直接双击启动项目.cmd，或按第二章用一次性ExecutionPolicy参数启动。

### 模型缺失或校验失败

YOLO缺失检查fire-models\fire_n.pt。SAM/DINO按第二章运行准备脚本；网络失败不会自动等同准备成功。自训权重丢失时从备份恢复原任务完整目录，或选择仍可用模型重新演示；不要改文件哈希绕过校验。

### 显存不足 GPU不可用或加载DLL失败

先关闭其他占显存程序，检测选fire_n、320或640，关闭SAM；训练减batch。确认项目Python的torch能识别CUDA，再检查显卡驱动。只用CPU可继续排查功能，但SAM实时摄像头可能因超过采样间隔而中断。不要随意把锁定NumPy或PyArrow升级成另一套版本。

### 摄像头打不开或一会儿就断开

先停止其他检测和采集，关闭相机会议等占用程序，检查Windows摄像头权限，再尝试设备0/1和采集后端。间隔过大提示通常与处理耗时有关，降低负载后重开。暂停会关闭设备，继续属于新观测段，时间和确认重置是设计行为。

### 能看到框却没有报警

检查状态仍在运行、报警置信度是否高于本帧置信度、是否同类同区域持续出现，以及帧数和时长是否均达到。面积辅助还要求SAM成功且达到区域面积阈值。单帧命中不直接记录事件，检测框不是已确认报警。

### 没有声音 没有录像或只保存部分片段

声音检查允许报警提示音、浏览器自动播放权限和系统音量。录像检查保存开关、FFmpeg的libx264、可用磁盘与历史错误；收集中继续处理足够的素材时间，编码中稍后刷新。前置不足或提前停止会保存实际范围，不能用重复画面补成完整窗口。

### 图片方向异常 导入失败或抽帧中断

检测与图片入库均按EXIF方向摆正，导出的掩码对应摆正后的图像。超大图片先缩小；损坏文件或视频时间异常先在本地播放器检查。数据导入逐条报告，失败项不算入库；已成功抽帧不会因后面失败自动回滚。

### 无法划分 无法导出或训练按钮不可用

演示/测试来源不参与正式划分，至少3个独立含图采集组。检查比例合计100%、版本是否因新导入而过期、全部图片最新复核是否通过、空标签是否确认负样本。Training只接受完整YOLO数据集，且须填写执行者与说明，同目录不能已有运行任务。

### 任务失败 中断或历史媒体缺失

Training选择任务展开参数与日志，先保留错误信息。取消/失败不算成功模型；中断任务目前新建重试。历史缺视频检查数据库与media是否一起恢复、是否等待编码；旧日志字段缺失显示未记录是正常兼容行为，不用当前值补填历史。

### 独立标注无法提交或质量报告不可生成

查看按钮上方原因，确认已经开始计时、累计大于0；空框需明确无火烟。计时运行中可直接提交，系统会自动暂停。检查是否已提交锁定或拿错访问码。管理端须等两人全部完成即可生成报告或分别导出，无须额外参考版本和仲裁说明。访问码忘记后不能从哈希还原，应联系保存访问码的人，不要为绕过问题新建同批任务或伪造原始提交。
