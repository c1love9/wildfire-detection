## 下一阶段执行顺序

1. 实际采集/整理、核验数量与授权来源，并以采集组和父视频隔离train/val/test；近似帧不能当独立场景补数。
2. 正式预标注/复核；另组织两名真人独立标注≥200幅，完成仲裁和预标注质量分析；控制工时实验的任务难度、质量与顺序。
3. 在冻结train/val上充分训练并选定方案，最后用独立test完成YOLO/DINO和优化对照。不能根据test反复调参。
4. 导入独立人工参考掩码，计算实际面积误差；补齐正式精度、误报率、人工工时及优化结果与局限。
5. 在现有模板版报告中填写个人信息，交付正式数据/权重及最终实验报告。当前报告中所有“待正式数据”位置保持待补。
