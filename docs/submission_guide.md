# 智能火灾报警系统提交说明

本包按原题六项验收要求组织，汇总真实数据、训练、独立测试、优化对照和可运行系统。报告使用教师提供的 Word 模板。数据、训练结果和评测保持原冻结版本，本次整理不改变标签，不重新选择测试集，也不生成新的实验成绩。

当前状态为“已完成系统和主要实验，仍有明确待补项”，不能签认为原题全部完成。700幅图片均已人工复核；其中507幅含火烟，193幅正常，自主整理来源的含火烟图495幅。严格数量仍差5幅自主火烟图和7幅正常图；已准备候选另存并明确不计数。

## 数据和标注核查

01/最终数据集的images与labels按train/val/test配对；类别以class_mapping.json和data.yaml为准。统计文件同时提供逐图记录、来源和场景声明；来源视频截取时间及SHA256可追溯。视频300段来自46个原视频，不是300次独立火灾事件。

公开无标签视频由成员选片、剪辑和抽帧，采用教师明确认可的课程“自行采集”统计口径，保留public原始来源，不写成本人实拍。各数据源许可与署名见最终数据集/licenses；不授予超过原始来源的再分发权利。

标注过程与质量保留同一200幅的A/B独立结果和原始时间、原/增强预标注、全部人工修改记录，可分别核查或导出，不强制逐图仲裁。工时根据负责人实测约5秒/幅外推，700幅预计节省51.46分钟、46.87%；样本数未提供，不是700幅逐图计时实测。框IoU仅表示定位一致性，不能作为SAM分割IoU或实际面积误差。

原冻结划分为484/140/76，约69.1%/20.0%/10.9%。已知同源视频组隔离，但D-Fire原始事件身份及公开预训练重叠未知；测试只有1幅正常图。不要把未确认候选加入旧版本后沿用本次成绩；补齐后另冻结新版本。

## 训练和性能的对应关系

基线train_984a486d3e6f459eb8eea567da186ef0由验证集选择，之后才做独立test；多尺度train_1f711de846be417dbe4d220af8b0e808为对照。两者均从同一COCO YOLOv8n初始化、50轮、640、batch=8、AdamW、lr=0.001、seed=42、FP32，唯一声明的优化因素为multi_scale。

|独立test模型|Precision / Recall / F1|mAP50 / mAP50至95|
|---|---|---|
|固定尺寸YOLO|62.77% / 41.79% / 49.76%|48.49% / 29.14%|
|多尺度YOLO|75.55% / 41.79% / 53.53%|49.99% / 28.25%|
|GroundingDINO Tiny|37.70% / 58.21% / 45.63%|50.29% / 38.18%|

统一比较工作区的本机YOLO约48.09 FPS、DINO约2.27 FPS；为预热后单帧推理计时，包含预处理、模型与后处理，不含画框、加载、磁盘和界面，不是SAM开启后的端到端视频播放帧率。目标检测使用P/R/F1与AP，不杜撰分类accuracy。协议、候选阈值、提示词和逐图预测见03。

多尺度F1提高约3.77个百分点，mAP50提高1.49个百分点，mAP50至95下降0.89个百分点，不能宣称全面提升。报警对照仅比较触发事件数和延迟，没有真实事件标注，事件减少量不能换算成误报率。50轮执行完整，但不证明充分收敛。

## 在新目录恢复和演示

1. 校验总包后解压，打开06_源码报告与复现/源代码/source_code.zip，将源码解压到全新项目目录。
2. 按05_系统演示/完整使用指南安装Python3.11、依赖、FFmpeg及显卡驱动。虚拟环境和驱动不随包提供。
3. 在新项目目录运行下面命令，将包路径替换为实际解压目录。工具逐文件校验且拒绝覆盖不同内容。

```powershell
.\.venv\Scripts\python.exe scripts\restore_final_delivery.py --package "D:\提交材料\智能火灾报警系统_提交材料"
```

4. 恢复后已有700幅及300段、两组训练、自训模型列表、比较历史和公开报警例子。SAM ViT-B、DINO Tiny/Base的固定版本完整本地快照一并恢复，推理无需再次下载；prepare脚本保留作损坏修复或单独源码安装时使用。
5. 双击“启动项目.cmd”，默认访问http://127.0.0.1:8501。原开发机已有8506服务时继续使用原页面，不必重复启动。
6. 按05中的现场指南演示：选择自训模型→命名通道A→修改模拟经纬度、水平角和俯仰角→视频检测与分割→面积曲线和分级报警→停止→历史截图/录像/位置→对比及优化记录。地图可关闭在线底图，仍显示模拟点位和视角。USB摄像头需现场硬件；模拟定位和视角不冒充实体GPS或云台。

恢复包去除了旧A/B访问码及其哈希，独立标签与历史可直接查文件；要新建独立标注访问任务须重新生成访问码。历史中的原电脑绝对路径作为原始证据保留，运行使用恢复后的相对目录。包内不含个人摄像头画面、账号token或虚拟环境。
