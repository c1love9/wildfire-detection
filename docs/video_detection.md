# 视频火焰与烟雾检测

本阶段把原先只播放样例的视频页改为逐帧运行YOLOv8检测。使用上游 `fire-models/fire_n.pt` 权重，输出火焰、烟雾的框、类别和置信度；支持内置样例、本地上传、CPU与CUDA。

后续已在这条链路上加入连续多帧确认、分级报警和持久化日志，使用与验证见 [alarm.md](alarm.md)。下面的帧检测记录保留原视频阶段的口径。

## 操作步骤

1. 按 [quick_start.md](quick_start.md) 启动项目，打开 <http://127.0.0.1:8501/Demo_Videos>，或从侧边栏进入 `Demo Videos`。
2. 在“视频来源”选择“内置样例”，再选择一段视频；也可以选择“上传视频”，上传MP4、MOV、AVI或MKV文件。文件扩展名受支持时，仍需视频编码能被本机OpenCV正常解码。
3. 模型先用 `fire_n`。有可用CUDA时默认使用GPU，也可以选择CPU。置信度阈值默认0.20，值越高，保留的检测框通常越少；“检测设置”中可调整重叠框抑制阈值，默认0.50。
4. 点击“开始检测”。首次加载模型需要等待；之后页面依次显示每一帧的检测结果。`fire`表示火焰，`smoke`表示烟雾，框旁数字是模型置信度。
5. 点击“暂停检测”会保留当前位置，点击“继续检测”从下一帧继续。点击“停止检测”会关闭视频读取；再次“开始检测”会从头检测。
6. 检测运行或暂停期间，来源和参数暂时锁定。先停止，再切换视频、模型或参数。视频自然结束后，页面保留最后一帧并显示累计统计，可以直接重新开始。
7. 展开“当前帧检测明细”，可查看类别、置信度与原图像素坐标。无法打开或解码的视频会显示错误提示，停止后可以更换文件。

## 显示内容与统计口径

|内容|含义|
|---|---|
|当前帧|已检测的帧号／视频提供的总帧数，从1开始计数。|
|视频时间|优先读取该帧在源视频中的时间戳，不用处理耗时替代。无有效时间戳时，按帧率估算并标注“估计”。|
|火焰、烟雾|当前这一帧保留的对应类别检测框数量。|
|处理速度|当前会话已处理帧数除以运行时间，包含页面更新等待，扣除暂停时间。|
|本帧推理|模型报告的单帧推理耗时，不包含完整解码、绘图、传输和页面刷新。|
|结束时的含火焰／含烟雾帧数|出现至少一个对应类别检测框的帧数；同一帧可同时计入两类。不是独立火源数量。|

每一帧都依次检测，不通过跳帧提高显示速度。界面约每0.1秒触发一次更新，实际速度还受推理、传输和浏览器影响，因此处理过程不保证按原视频帧率播放，也不播放原视频音频。源视频时间仍与当前检测画面对应。

程序只保留最新一帧的显示图像和检测明细，不累计全部视频图像。显示画面最多缩放至960×720范围，明细坐标仍对应原始分辨率。画面编码后随页面更新发送，避免停止或切换视频时浏览器继续请求已清理的临时图片。停止、自然结束或处理出错后释放视频读取资源；暂停时保留读取位置。

上传内容按文件摘要保存于本机 `artifacts/uploads/`，重复上传同一文件可复用。该目录已被Git忽略，不随提交上传；视频不会在检测结束时自动删除。

## 重新检查

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe .\scripts\verify_video.py
```

该脚本实际加载权重、遍历四段完整视频、验证时间与坐标、检查CPU和错误文件，并运行页面控件检查。成功后刷新 `reports/video_detection.json`；计算设备自动优先选择CUDA，不可用时选择CPU。浏览器记录来自本机Edge的独立验收，运行此脚本不会刷新 `video_browser.json`。浏览器复验时可按上面的操作步骤检查相同场景，暂停后应看到帧号稳定，继续后应递增。
