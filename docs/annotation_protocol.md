# 本轮预标注选择依据与调参记录

本文件保留初始配置与准备过程；后续已经完成的200幅阈值筛选、40幅提示词对照和13幅原配置复跑，详见[预标注调参与误差诊断实测记录](preannotation_diagnosis.md)及[机器报告](../reports/preannotation_diagnosis.json)。原配置仍保留，尚无经独立验证的优选设置。

## 实际采用的模型与提示词

GroundingDINO Tiny固定版本为a2bb814dd30d776dcf7e30523b00659f4f141c71，权重SHA-256为1a2412ef99bd74bcd3c2a246fa1e48581f8889a1300c9051974741314fc042f3。没有在本项目火灾数据上微调，微调样本数为0。初始整理时，模型在本机GPU上实际处理500幅入选火烟场景帧，另200幅D-Fire正常候选沿用来源空标签，当时尚未人工复核。

200幅双人独立任务准备阶段又对其中40幅正常候选实际运行相同固定DINO配置，追加新候选版本，并在两人均0提交时留痕重新冻结任务候选。该任务最终200幅均有实际模型输出，避免把来源空标签充作DINO在正常图上的推理结果。之后另160幅正常候选也补跑相同配置，160/160成功、失败0幅，目前700幅均有实际模型输出；历史来源空标签与A/B冻结候选保留。候选生成不产生人工通过记录。

|设置|实际使用值|依据与限制|
|---|---|---|
|火焰提示词|fire. flame. burning. blaze.|采用原题给出的类别与同义词，分别覆盖火灾、可见火焰和燃烧外观；未证明每个词都有增益|
|烟雾提示词|smoke. smoke plume. heavy smoke.|采用原题建议的烟雾、烟羽与浓烟表达；白烟与薄烟仍可能漏检|
|框与文本阈值|0.30与0.25|沿用项目固定初值以保证可复现，不是人工参考上选出的最优值|
|同类NMS|IoU 0.50，每类最多50框|减少同类重复候选；保留fire/smoke跨类重叠，交人工判断|
|尺寸与设备|短边640，长边最大1066；CUDA FP32|Windows下使用现有Transformers实现并关闭自定义CUDA编译；实际环境留存在运行记录|

每次按类别分别推理，再把该类提示词得到的候选映射到fire或smoke。保留原始匹配词、置信度和坐标，不能只根据“burning”等输出词另建第三类别。

## 本轮实际过程

1. 固定原题建议的同义词与上述初值，在来源选片后运行候选生成。筛选过程中替换失效或被覆盖层污染的素材后，按原图哈希重新计算对应候选，未复用旧图结果。
2. 预标注元数据保存在data/minimum_collection/preannotations/grounding_dino_metadata.json及正式库annotation_runs；逐图JSON保留输入哈希和候选，人工记录尚未自动生成。
3. 最终候选中有29幅来源正样本为空。这个数字是漏框待核查清单的大小，不是漏检率，也没有据此将阈值调整后宣称改善。
4. A/B完成后已执行带人工参考的初步对照：200幅训练图上的8档框阈值筛选、40幅分层训练子集上的三套提示词比较。提高阈值会明显损失召回，简化提示词未显示稳定改善，原配置未改。完整数值和局限见[实测记录](preannotation_diagnosis.md)，不虚构优化成功。

## 后续配置验证方法

先确定训练或验证样本及人工参考，固定模型、图像清单和计算设备。可在同一清单上比较单词提示与当前同义词组，再依次比较框阈值；每次只改变声明的因素，保存配置、逐图预测、P/R/F1与人工错误类型。用验证结果选择配置后冻结，不能拿test调参。具体候选阈值可由负责人在实验前声明，未实际运行的配置保持“计划”，不写成历史。

GroundingDINO也用于开放域模型对比，报告和Comparison任务记录已经披露。换提示词不能自动保证参考标签独立；正式test仍需人工协议和来源隔离。原题建议标注与对比使用不同模型或不同提示词，属于建议，不替代该披露与独立参考要求。
