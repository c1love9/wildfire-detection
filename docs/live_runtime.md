# 现场运行包使用说明

本包用于当前这台Windows电脑现场演示。代码、700幅图片、300段视频、人工标签、两组训练、冻结评测、SAM/DINO快照与公开报警历史均放在包内。它复用原项目已经安装好的Python 3.11环境和FFmpeg，不重复打包虚拟环境。

请保留原项目 `D:\GPTWORK\fire-alarm-system\.venv` 以及本机FFmpeg。可以把本包解压到本机另一个文件夹，但不要在压缩包内直接启动。建议路径短一些，例如 `D:\火灾演示`，避免多层嵌套。

## 三个入口

1. 双击“演示前检查.cmd”。会检查依赖、GPU、模型、视频、数据库和FFmpeg。首次完整检查还会校验包内静态文件的SHA256。看到“环境检查通过”后继续。
2. 双击“启动现场演示.cmd”。服务在后台运行并自动打开浏览器，通常为 `http://127.0.0.1:8506`。端口被占用时自动选择后续端口，以启动输出或 `.runtime/run/server.json` 的实际地址为准。重复双击不会再启动本包的第二个服务。
3. 结束时先在网页点“停止检测”，等片段保存完成，再双击“停止现场演示.cmd”。关闭浏览器标签不等于停止服务。停止入口只处理本包自己启动、身份匹配的服务，不停止原项目或其他应用。

“启动项目.cmd”也指向同一个现场启动入口。启动失败的详情记录在 `.runtime/run/server.log`，最近环境结果在 `.runtime/run/environment_check.json`。这些文件在运行后生成。

## 三分钟现场主线

启动入口会在Home和Demo Videos默认选择本次baseline自训best模型，训练任务尾号 `da186ef0`。仍可手动切换模型，General模式保留COCO通用模型。

|时间|操作|要展示的效果|
|---|---|---|
|前40秒|视频页停止状态选命名通道A，修改模拟经纬度、水平角、俯仰角|位置和视角可交互|
|接下来1分钟|开启SAM分割与截图片段，开始检测，演示暂停和继续|检测框、掩码、面积、曲线、连续确认与等级提示|
|接下来40秒|停止并等编码完成，进入Alarm History刷新，选本次事件或已有公开样例事件|地图位置、截图、录像回放与趋势|
|最后40秒|停止后切换B或USB，开始再停止|通道切换、输入画面更新、设备释放|

上场前预热一次YOLO与SAM，确认已有公开报警片段可播放。短演示可在停止状态把确认前/后保存窗口设为1秒/2秒，并说明这是演示配置。保持默认5秒/10秒时，要让素材时间走过后录窗口再停止。普通USB画面无火烟时不出现检测框属于正常。

摄像头角度与GPS按任务书允许采用模拟。地图标注监控点，不声称测出了火源真实坐标。离线时关闭在线底图，仍可展示经纬度、视角、点位和历史快照。SAM和DINO均已随包附上本地固定版本，推理无需再次下载。

## 数据、训练及标注报告

- Dataset展示700幅、300段及冻结划分。Annotations展示已完成复核和修改历史，现场只查看已有记录即可。
- Training查看尾号da186ef0和f8b0e808的两组50轮任务。Comparison、Experiments查看已有结果，不必现场重新训练或重跑全量测试。
- Quality选择“报告与导出”，管理访问码从 `.runtime/标注报告管理码.txt` 复制。该码是为本演示副本新建的查看入口，未拷贝旧访问码，也没有修改A/B原始标注。文件不要投影或上传公开仓库。
- 运行后的新报警只写入本包的数据库、媒体目录，不会追加到原项目。原数据、模型、A/B标注与冻结实验保持原记录。修改通道/坐标也仅影响本包配置和今后事件，不改变已有历史快照。

## 答辩材料

“演示资料”包含10分钟PPT、逐页讲稿、完整操作指南、冻结实验说明、性能图表及备用视频。若本次启动自动更换端口，PPT第12页系统链接也需使用实际地址。备用视频是此前录制的公开素材操作，设备异常时可明确说明后播放，不能当成本次现场运行。

## 常见问题

|现象|操作|
|---|---|
|提示Python环境不存在|确认原项目.venv还在。也可在新包目录运行scripts/setup.ps1重装依赖，或设置FIRE_DEMO_PYTHON指向已安装的兼容环境。当前包不承诺换电脑后免安装。|
|缺少FFmpeg或片段不生成|本包使用本机已安装FFmpeg，其地址记录在.runtime/machine.json。不要只移动可执行文件而遗漏依赖。|
|页面打不开|查看.runtime/run/server.json中的实际地址及server.log。再次双击启动会复用本包已有服务。|
|切换按钮灰色|先停止检测，再换模型、来源或通道。|
|推理慢|插电并选择CUDA。SAM分割会增加耗时，模型评测FPS不能当成完整系统帧率。|
|摄像头被占用|停止检测，关闭占用摄像头的软件，再试USB编号0；仍失败则用本地视频展示其余流程。|
|看不到报警|检查持续时间、同一区域连续命中及报警置信度。出现框不等于已经满足确认条件。|

本包使用原700幅冻结版本。严格数量仍差5幅自主火烟与7幅正常图，场景/设备覆盖和独立分割面积误差仍待补；打包与现场启动不会改变这些实验边界。
