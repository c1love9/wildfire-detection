# 独立测试性能图表使用说明

图表附件位于`artifacts/performance_visualizations_20261108/03_性能图表_交付版`，解压附件ZIP后双击“打开图表.html”即可离线查看。原2.71GB总提交包保持原样，这个附件作为03性能评测的新增材料，不覆盖旧manifest。

全部成绩使用冻结76幅test，未使用train/val成绩充当最终性能；全部700幅只用于划分数量图。YOLO和DINO原始预测及优化两组预测重新计算后，与保存指标一致。已知来源组、图像ID和文件SHA256均未跨集合重叠，但test仅2个已知采集组，正常图仅1幅，因此覆盖和正常误报率证据仍不足。

|图|报告中的建议位置|说明|
|---|---|---|
|01 检测性能|性能结果主图|P/R/F1、mAP50与mAP50至95，明确不同工作点|
|02 速度与资源|效率分析|同一设备、batch1、FP32、同一次比较；含预/后处理，不含SAM和界面|
|03 划分与分布|数据与评测方案|484/140/76、正负分布、类别框数及来源分布，显示已知限制|
|04 分类别错误|误检漏检分析|fire/smoke的召回率和TP/FP/FN计数|
|05 PR曲线|阈值与检测质量分析|只使用冻结低阈值候选，不借此重新选择部署阈值|
|06 图像级Accuracy|补充准确率说明|定义为整图是否至少检出一个火烟框，不能代替框定位质量；解释全判正也有98.68%的偏倚|
|07 策略对照|优化实验|保留多尺度mAP50至95下降0.89个百分点的实际结果|

正文建议优先插入01、02、03；04、05用于解释失败案例与阈值，06作为明确口径的补充，07放优化章节。PNG用于Word，SVG保留可编辑文本，PDF用于打印，合并PDF共7页。建议约180mm宽插入，图中文字最小约6.8pt；不要继续过度缩小。

“准确率”分开报告：检测框Precision为62.77%，图像有无火烟的Accuracy为80.26%。DINO的图像级Accuracy98.68%与全部判有火烟的简单参照相同；不能仅凭这个高值声称模型可靠。正式测试mAP50为48.49%、mAP50至95为29.14%，FPS48.09，均保留各自协议。

只有一个训练种子和一套划分，没有跨种子显著性或置信区间。图02箱线图表示全部76幅逐图耗时变化，不是跨种子误差条，也不是76个独立事件。

复现命令在项目根目录执行；输出目录必须尚不存在：

```powershell
.\.venv\Scripts\python.exe scripts\plot_test_performance.py --package "已解压的智能火灾报警系统_提交材料目录" --output "新的图表输出目录"
```

脚本只读原包、验证输入SHA256及测试ID、重新计算已保存预测，不调用模型推理或训练，不改标签。依赖使用本项目已有的matplotlib、NumPy、Ultralytics和PyTorch；中文字体默认Microsoft YaHei。

附件含图注、源CSV/JSON、PR点、逐图耗时、图像级混淆计数、源文件指纹、划分审计和生成脚本。尚缺的真实正常图、场景确认、跨设备证据、分割面积误差不会由图表自动补齐。
