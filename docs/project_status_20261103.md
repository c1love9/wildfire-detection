## 尚未关闭的关键事项

1. **最终训练标签。** 700幅中只有1幅登记普通人工通过。已完成的200幅A/B可以复用为标签基础，选定一份后只核查有问题之处，保留另一份用于质量对照，不要求再独立标注一遍。其余自动候选仍须检查。普通复核页尚未提供一键采用A/B或本轮21幅试训修正结果的入口；复用前应把它们作为有真实来源的候选载入，而不是批量伪造人工通过。
2. **最终数量与场景。** 临时包排除了5幅来源正样本，剩495幅来源火烟图和200幅正常候选。若正式也排除这5幅，需要补入至少5幅有效火烟图，维持500+200最低数量。正常图需确认无火烟；早期小火星、实际燃烧阶段及未说明场景仍需核实，不能凭远处小火焰或浓烟外观直接宣布覆盖。
3. **正式训练与独立评估。** 用最终标签和冻结分组划分训练，保留参数、损失、mAP曲线及best/last；依据val选模型与阈值，再在冻结test评测P/R/F1/mAP50/mAP50-95、速度与正常场景误报率。当前3轮临时指标不替代这一步。
4. **正式对照实验。** YOLO与未微调DINO使用同一测试集、尺寸、设备和匹配协议；固定尺寸与多尺度使用固定初始条件，完成真实对照后再判断优化是否有效。
5. **面积误差与工时。** 正式人工参考掩码0条，独立面积误差尚无；质量工时对照记录0条，辅助复核有效用时未计量。A/B提交中的seconds字段不能直接补出缺失的辅助复核用时。后续在实际复核时暂停/恢复计时，按可比质量与工作量估算节省量，不倒填此前时间。
6. **最终交付更新。** 填入真实个人信息与正式结果，更新模板报告、使用指南、演示、源码快照和交付清单，另交最终数据、权重、日志及哈希。
