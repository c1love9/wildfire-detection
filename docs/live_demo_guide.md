## 二 开场准备与图片检测

### 上场前十分钟

1. 给电脑接电，关闭会长时间占用显卡或摄像头的程序，确认项目文件夹、数据、SAM/DINO和本人权重仍在原位置。当天不临时升级依赖。
2. 如果8506能打开，直接使用现有服务。若打不开，双击项目根目录“启动项目.cmd”，保留弹出的运行窗口，使用它显示的地址，通常为8501。
3. 展开左侧导航栏。进入Home，确认模型列表出现尾号da186ef0的自训模型。未出现时先处理第七部分的“找不到本人模型”。
4. 提前在Home开启一次SAM并等待完成，预热模型。演示主线不需要现场重新下载模型；Comparison若只查看历史结果，不用再加载DINO推理。
5. 在Demo Videos试跑通道A，提前产生一条可播放的公开样例报警记录。准备“系统演示.mp4”和新版报告，遇到临时设备问题时作为已录制材料展示。
6. 需要展示声音时，先将音量调低，再主动开启“允许报警提示音”；默认关闭声音也可以演示弹窗和颜色变化。

### Home 图片操作

1. 点击左侧Home。Select Model Type选择“Fire Detection”，Select Model Size选择尾号da186ef0的自训best模型。
2. “推理图像尺寸”选640；Inference Device在CUDA可用时选GPU；Confidence Threshold可用0.25，IOU Threshold保持0.50。
3. Select image source选择“Demo Image”，Select demo image选“image12.jpeg”。若该图效果不明显，可选已排练的“image10.jpeg”。
4. 勾选“开启火烟像素分割”，等待Prediction更新。页面自动推理，无需寻找“开始检测”按钮。
5. 展示当前检测框、类别和置信度，再指出彩色掩码、轮廓以及火焰、烟雾、并集占比。可下载Download Prediction及二值掩码作为导出示例。

讲解提示：“YOLO找出火焰和烟雾位置，SAM根据这些框分割像素。面积是占当前画面的比例，同一像素在并集中只计一次。”

部分上游演示图片原本带有旧框；本次结果以当前检测数量和明细为准。这一环节验证系统流程，正式精度来自后面的独立test。

## 三 视频报警与通道切换

### 查看绑定并开始通道A

1. 点击Channels，查看“编辑通道”和下方表格。默认监控通道A绑定fire1.mov、B绑定fire2.mov，USB通道绑定0号摄像头。位置和视角是可交互的模拟信息。
2. 进入Demo Videos。“视频来源”选“命名通道”，“监控通道”选“监控通道 A”。“检测模型”重新选择尾号da186ef0的自训模型，计算设备选可用GPU。
3. 展开“检测设置”，勾选“开启火烟像素分割”，推理图像尺寸640，NMS IoU保持0.50。检测置信度可用0.25；“报警规则”先保留排练时的默认值。
4. 要展示角度和GPS交互时，开始前展开“监控点位置与视角（模拟）”，位置记录方式选“模拟定位”。可将“模拟水平角（度）”改为120、“模拟俯仰角（度）”改为-20，或微调经纬度，移开输入焦点使值生效。下次开始检测后展示对应点位和方向，说明并未操纵真实云台。
5. 展开“报警截图与片段”，确认“保存报警截图和片段”已开启。默认确认前5秒、确认后10秒；显示的实际片段范围可能因视频起点或提前停止而缩短。
6. 点击“开始检测”。观察当前帧、视频时间、目标数量、处理速度和监控点。等同一区域满足连续帧与持续时间条件后，展示关注、预警或报警提示。
7. 出现弹窗时点“确认并关闭”。这只关闭提示，不代表火情已恢复。展开“本次报警变化（最近50条）”和“面积与等级曲线”查看记录。

### 暂停 继续与切换

1. 点“暂停检测”，观察当前帧和视频时间保持不变，曲线不继续新增采样；再点“继续检测”。暂停时模型与通道仍锁定。
2. 首次确认后，让“视频时间”再前进至少10秒，为默认的后录窗口留足素材；再点“停止检测”，等待编码完成。这里看素材时间，不以自己等待了几秒代替。
3. 停止后，将“监控通道”改为B，核对关联监控点和视角，再点“开始检测”展示另一来源。切换后重新确认，不继承A通道的报警状态。
4. B通道展示完成后点“停止检测”。可点“导出面积趋势 CSV”展示趋势导出，再进入历史页。

讲解提示：“单帧命中先作为候选，同类同区域持续命中后才确认。分级同时参考置信度、持续时间和可用面积；停止观测不会被当成火情恢复。”

若现场时间紧，可在开始前将录制窗口设为前1秒、后2秒，并明确这是演示配置；不要将短片段描述成已经保存了前5秒、后10秒。

## 四 历史地图回放与摄像头

### 找到刚才的事件

1. 点击Alarm History，再点“刷新记录”。“输入来源筛选”“最高等级筛选”“通道筛选”先选“全部”，避免筛掉刚发生的关注级事件。
2. 在“查看事件变化”选择刚才A或B通道的事件。看“本次检测模型”，确认显示自训模型；必要时展开“模型与推理参数快照”核对来源和任务。
3. 展示经纬度、水平角、俯仰角以及地图点位和视场。说明它们是事件发生时的监控点快照；当前配置更改不会改写旧事件的位置。
4. 向下找到“报警截图与片段”，展示首次确认截图，点击视频播放。查看实际开始、结束时间和是否标记为部分片段。
5. 查看事件期间的面积及等级趋势，点击“导出当前筛选 CSV”或对应趋势CSV，证明记录可导出。旧事件未保存的字段显示未记录，不补造。

讲解提示：“这里回放的是已确认事件，能追溯当时的模型、通道、位置、截图、片段和曲线。地图标的是监控点，并不表示测出了画面内火源的真实经纬度。”

### USB摄像头现场输入

1. 回Demo Videos，确保上一观测已停止。选命名通道中的“USB 摄像头”；也可把视频来源改为“摄像头”，使用默认编号0。
2. 保持本人模型。为减少开销，USB环节可先关闭分割；为避免留下现场人员画面，可关闭“保存报警截图和片段”。这些设置都在停止状态调整。
3. 点“开始检测”，轻轻改变摄像头方向，展示画面随现场变化。普通桌面没有火烟时无框是正常结果，不能要求系统为了演示强行报警。
4. 点“暂停检测”，摄像头关闭；点“继续检测”，设备重新打开并创建新观测段。最后点“停止检测”释放设备。

讲解提示：“USB与视频使用同一套检测和报警流程。USB只处理最新采样帧；暂停再继续要重新确认，防止跨未观察的时间拼接火情。”

地图底图需要网络；离线时取消“显示在线地图底图”，仍保留监控点和方向示意，并展示经纬度及角度文字。摄像头若打不开，按第七部分排查，再使用已验证的本地视频通道继续其余功能演示。

## 五 训练 模型对比与优化结果

### Training 查看真实训练

1. 点击Training，向下找到“任务与实验记录”。在“查看任务”选择尾号da186ef0的任务，确认状态已完成、实际50轮。
2. 展示损失和验证mAP曲线，查看保存图表results.png；展开“参数与工作日志”，指出网络YOLOv8n、640输入、batch8、AdamW、学习率0.001和种子42。
3. 展示best.pt可下载的位置。说明best和主方案按验证集选择，test没有参与选模；另一组只打开多尺度训练，两组各50轮。

讲解提示：“模型是在已复核的700幅冻结版本上开展实验，其中训练484幅、验证140幅、测试76幅。26幅优先复核图不是全部训练集。”

### Comparison 查看统一test

1. 点击Comparison，YOLO对比模型选尾号da186ef0，工作区选“统一test评测”。向下看“历史对比结果”，在“对比记录”选尾号028f0672的已完成记录。
2. 展示下表对应的实际结果，再点“下载对比CSV”。已有结果不必点“运行统一测试评测”重算。

|指标|自训YOLO|GroundingDINO Tiny|
|---|---:|---:|
|Precision / Recall|62.77% / 41.79%|37.70% / 58.21%|
|F1|49.76%|45.63%|
|mAP50 / mAP50至95|48.49% / 29.14%|50.29% / 38.18%|

这些是同一冻结test、640、batch1、FP32、同GPU下的结果。P/R/F1固定conf0.25，AP使用低阈值候选；计时含预后处理，排除读盘、加载和画框，不等于开启SAM后的整套系统速度。DINO未微调，也曾用于预标注，报告已披露。

### Experiments 查看优化

进入Experiments，查看已完成的“优化实验记录”和两组曲线、test差值。多尺度相对固定尺寸的F1提高约3.77个百分点，mAP50至95下降约0.89个百分点；说明本次优化并非所有指标都改善。现场展示保存结果即可。

## 六 数据标注证明与常见提问

### 老师问数据和标注时

1. Dataset展示归档统计与冻结划分：700幅图、300段视频共900秒。最终507幅含火烟、193幅正常；自主整理且含火烟495幅，尚需确认补足5幅自主火烟图和7幅正常图。
2. Annotations展示已有预标注版本、人工复核状态和YOLO导出。700幅最新复核已通过，类别固定0=fire、1=smoke；只查看，不重新批准或改动原记录。
3. Quality选“报告与导出”。管理员码在排练时私下准备，指南不记录访问码；按原任务说明进入后展示A/B各200份已提交及双参考质量报告。若现场不便登录，展示交付包04中的原始标签与报告。
4. 说明原Tiny和增强候选分别保留。增强流程包含DINO Base与上游火烟YOLO补充，不能将它称为纯DINO零样本。

### 常见提问的回答要点

“怎样减少单帧误报”：同类别、同区域关联，连续帧和持续时间满足后才确认；分级再参考有效面积。仍会有误检，不能只凭演示证明误报率低。

“面积是不是实际平方米”：这里是火焰、烟雾像素占画面的比例；没有相机几何标定，不转换成平方米。当前分割IoU和实际面积误差仍缺独立参考。

“IoU是多少”：增强预标注相对A、B匹配框的平均IoU为0.7317、0.7416；须同时看未匹配框。这是检测框定位一致性，不是SAM掩码IoU。

“省了多少人工”：按本人提供的实测约5秒/幅推算，700幅辅助复核约58.33分钟，相比A/B单人基线估算节省51.46分钟、46.87%；没有把推算写成700幅全量配对实测。

“为什么两页指标不同”：先看val还是test，再看阈值。Training主要展示val和Ultralytics口径；Comparison展示固定阈值的统一test。分割显示速度也不同于纯检测评测速度。

“是否全部达到题目要求”：系统和真实训练实验已有证据；数量差额、严格场景和面积分割误差仍待补。test只有1幅正常图，跨设备身份也不完整，不据此夸大误报率或泛化性能。

“哪些是自己完成的”：项目基于开源Fork整合改进，保留上游来源；两组YOLO是本项目数据训练，DINO和SAM使用固定预训练版本。实现与文档有AI辅助，人工标注与复核按实际人员记录说明。

## 七 故障处理与结束演示

|现场现象|处理方法|
|---|---|
|网页打不开|查看启动窗口是否运行、URL端口是否一致。当前服务8506与默认重启8501不要混用。窗口关闭则重新启动。|
|找不到本人模型|确认进入原项目目录，data/fire_dataset和training中的本人权重齐全。换电脑应先恢复交付数据，不只复制Git代码。|
|分割提示缺模型|提前运行prepare_sam.py准备SAM。现场来不及则先展示纯检测及已有演示材料，并说明本次未现场运行分割。|
|推理明显变慢|确认计算设备是GPU，停止其他显卡任务。先停止，再按需关闭分割；CPU或YOLO+DINO+SAM同开会增加等待。|
|开始或切换按钮灰色|运行或暂停时会锁定输入和模型。先点停止检测，再换通道、模型或参数。|
|有框却没报警|检查报警置信度和持续条件，观察素材视频时间与同一区域连续命中；检测框出现不代表报警门槛已满足。|
|没截图或片段不可播放|确认运行前开启保存；等待后录窗口和编码，刷新历史，选本次事件。检查FFmpeg。提前停止的部分片段按实际范围说明。|
|USB黑屏或占用|先停止，关闭其他摄像头应用，再试编号0或Windows摄像头后端。仍不可用时用本地视频演示其余流程，说明现场设备问题。|
|历史事件找不到|刷新记录，把输入来源、最高等级和通道筛选改为全部；关注级事件不会出现在“最高等级＝报警”的筛选中。|
|地图底图不加载|取消“显示在线地图底图”，保留点位和方向，继续展示坐标、角度与事件快照。|

备用启动方法：在项目文件夹打开PowerShell，使用以下命令启动8506；若该端口已有正常服务，直接访问即可。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File scripts\start.ps1 -Port 8506
```

结束时回Demo Videos点“停止检测”，等待保存完成，再关闭服务窗口；保持源数据、训练权重和旧日志不变。若重新运行了公开样例，产生新的报警记录属于正常现象。

备用视频位于项目内artifacts/final_completion_20261108/demo/系统演示.mp4，时长约3分9秒；排练时先打开所在文件夹。
